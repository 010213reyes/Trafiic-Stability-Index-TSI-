# Scripts de modelado

Esta carpeta queda reservada para experimentos reproducibles de ciencia de datos.

Los scripts de modelado deben separar:

- construccion de caracteristicas;
- particion temporal;
- entrenamiento;
- evaluacion;
- exportacion de metricas y parametros.

No se agregan entrenamientos hasta cerrar la definicion de etiqueta, unidades, frecuencia y validacion temporal.
