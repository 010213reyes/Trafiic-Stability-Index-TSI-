# 03 Validacion

Define particiones temporales, metricas, sensibilidad, estabilidad y comparacion entre modelos.

`01_Validacion_Modelos_Internacional.ipynb` evalua predicciones por fuente y calcula un intervalo bootstrap de la mejora frente a persistencia. La mejora fue positiva en 4 de 5 fuentes; Madrid queda como excepcion con solo 5 filas de prueba. Guadalajara se reserva para una etapa futura y no se usa como criterio en esta fase internacional.
