# 04 Integracion de la demostracion

Conecta los artefactos aprobados de MLOps con Streamlit sin trasladar entrenamiento, limpieza ni lógica de versionado al código de presentación.

## Entregables

- contrato entre la inferencia y la interfaz;
- consulta de resultados versionados;
- mensajes para ausencia de datos y errores;
- demostración local del flujo completo.
