# Documentacion TSI

`docs/` es la fuente canonica de la investigacion internacional nueva.

## Fases

- `00_arq_y_decisiones/`: alcance, arquitectura y decisiones.
- `01_mineria_datos/`: fuentes, variables, riesgos y diccionario.
- `02_ingenieria_datos/`: procesamiento, contratos y SQL.
- `03_analisis_datos/`: plan, EDA, calidad, temporalidad, comparacion e indicador.
- `04_ciencia_datos/`: modelado y validacion futura.
- `05_mlops/`: reproducibilidad, automatizacion y despliegue.
- `06_interfaz_streamlit/`: alcance de la interfaz.

El orden de trabajo es: arquitectura, mineria, ingenieria, analisis, ciencia de datos, interfaz y MLOps.
