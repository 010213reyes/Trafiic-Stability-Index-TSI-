# Entregables de la subfase de planificacion

## Entregables

1. Matriz de preguntas analiticas.
2. Criterios de comparabilidad entre fuentes.
3. Definicion de filtros de calidad e inclusion.
4. Inventario de salidas para Python, Jupyter y SQL.
5. Criterio de cierre para iniciar el EDA.

## Salidas por herramienta

- **Python:** funciones y scripts reproducibles para perfiles, controles y exportaciones.
- **Jupyter:** exploracion, visualizaciones y explicacion de hallazgos.
- **MySQL:** consultas de conteo, cobertura, calidad y agregacion despues de la carga completa.

## Criterio de cierre

La subfase termina cuando las preguntas, campos, unidades, filtros y salidas esperadas estan definidos. El siguiente paso sera construir el perfil exploratorio sin modificar los datos fuente.
