# Datos raw internacionales

Esta carpeta conserva las fuentes externas originales de la investigacion nueva. No se modifican durante la limpieza.

Las transformaciones se registran en `data/01_processed/` y las salidas limpias en `data/02_clean/`.

La fuente, licencia, cobertura, unidad y limitaciones de cada conjunto se documentan en `docs/01_mineria_datos/`.
